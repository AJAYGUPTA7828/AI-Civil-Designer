# AI Civil Designer – Smart Planning for Homes, Bridges & Roads

## Overview
AI Civil Designer is an AI-powered civil engineering tool that helps users plan, estimate, and visualize construction projects instantly. It is designed for engineers, contractors, students, and common people. By selecting a project type (Home, Bridge, Road, or Other), entering material quantities and budget, users can get cost estimation, design suggestions, and blueprint previews in seconds.

## Features
- Select project type: Home, Bridge, Road, Other
- Input cement, steel, bricks, and budget
- Instant cost estimation with detailed breakdown
- Multiple design suggestions:
  - Homes: Compact House, Duplex
  - Bridges: Small or Large
  - Roads: Village road or Highway
- Blueprint preview and planned 3D visualization
- Simple interface, fast results, universal usability

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Flask)  
- **AI Logic:** Rule-based formulas (future ML integration)  
- **Visualization:** Chart.js (cost charts), SVG/D3.js (blueprints), Three.js (3D preview)

## How It Works
1. Select project type (Home/Bridge/Road/Other).  
2. Enter cement, steel, bricks, and budget.  
3. Click **Generate Designs**.  
4. Instantly view cost estimation and design suggestions.
